The app contains an editable **My birthday** field for Kudakwashe. The user's actual birthday was not available in the stored project context used for this build, so no date was invented or hard-coded.


## Kudisa Calendar & Reminder System

The single-app build includes:
- Kudakwashe birthday: 17 July 2003
- Tadisa birthday: 10 October 2005
- Relationship anniversary: 7 July
- Shared calendar with marked important dates
- Upcoming-date countdowns
- Custom important dates
- 30-day / 7-day / 1-day / day-of-event reminder choices
- In-app reminder alerts
- Browser notification permission support
- Persistent reminder settings

The relationship-planning specification also includes the 2/2/2 rhythm:
- every 2 weeks: evening out
- every 2 months: weekend away
- every 2 years: week away

This repository is a single responsive vanilla HTML/CSS/JavaScript app and is suitable for GitHub Pages. Background push notifications when the site is completely closed require a production push backend/service worker integration.
